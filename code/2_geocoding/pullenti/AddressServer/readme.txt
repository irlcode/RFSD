Запуск из командной строки:
1) dotnet Address.Server.dll (на всех ОС) - через dotnet для версии на .NET Core
2) Address.Server.exe (под Windows) - для версии на .NEt Framework

Сервер запускается и взаимодействует с Pullenti Address SDK через http-протокол, напрямую обращаться
к серверу не надо, а использовать функцию AddressService.SetServerConnection(uri), и в дальнейшем
все функции AddressService будут осуществляться через сервер.
По умолчанию, адрес (uri) для доступа с локальной машины http://localhost:2222, но в принципе сервер можно 
запускать и на любой машине в сети.
Для остановки сервера нужно нажать в консоли любую клавишу или прервать процесс системным образом.

Возможные параметры:
-gar ... - имя папки, в которой находится индекс ГАР ФИАС;
-port ... - порт, по умолчанию 2222;
-address ... - внешний IP-адрес, по умолчанию все;
-noterminal true - не выводить никаких сообщений в консоль и не ждать нажатие клавиши для останова;

Параметры можно поместить файл commandline.txt в той же папке, что и исполняемый модуль сервера.

ВНИМАНИЕ! Под Windows возможно придётся запускать с правами "Администратор", так как иначе
система не даст работать по указанному порту (или как-то его открыть системным способом, не знаем каким...).
